# Google Cloud

## Brief Overview

Google Cloud is a cloud computing platform provided by Google. From my research, I learned that Google Cloud provides different services for computing, storage, networking, data analytics, AI, security, and application development. It helps organizations use computing resources over the internet without having to maintain all of the physical infrastructure themselves.

## Global Infrastructure

Google Cloud has a global infrastructure made up of regions and zones in different parts of the world. From my research, I found that Google Cloud currently has 43 regions and 130 zones. Its global network also connects many countries and territories through Google's fiber network.

The regions and zones help organizations deploy their applications closer to their users, which can improve performance and availability. Workloads can also be distributed across different locations to help support reliability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can use the console to create, configure, monitor, and manage their cloud resources from a browser.

## Four (4) Core Services

### Compute Engine

Compute Engine is a computing service that provides virtual machines on Google Cloud. It can be used to run applications and other workloads using virtual computing resources.

### Cloud Storage

Cloud Storage is a service for storing data in Google Cloud. It can be used to store files, backups, and other types of data.

### Cloud SQL

Cloud SQL is a managed relational database service. It allows organizations to use databases in the cloud without having to manage all of the physical database infrastructure themselves.

### Virtual Private Cloud (VPC)

Virtual Private Cloud (VPC) provides networking capabilities for Google Cloud resources. It allows organizations to create and manage networks for their cloud workloads.

## Three (3) Advantages

### 1. Scalability

Google Cloud provides on-demand computing resources that can be scaled based on an organization's needs. This allows businesses to handle changes in workload without having to purchase additional physical infrastructure.

### 2. Global Infrastructure

Google Cloud has regions and zones in different locations around the world. This gives organizations more choices for deploying applications and can help improve performance and availability.

### 3. Security

Google Cloud provides built-in security features and infrastructure designed to help protect organizations, their data, and their applications.

## Typical Enterprise Use Cases

From my research, I found several ways organizations can use Google Cloud. These include scaling infrastructure when demand changes, storing large amounts of data, developing and testing applications, performing big data analytics, and preparing for disaster recovery.

Organizations can also use Google Cloud for AI and machine learning workloads. Cloud computing allows businesses to access computing resources and technologies without having to build and maintain their own large physical data centers.
