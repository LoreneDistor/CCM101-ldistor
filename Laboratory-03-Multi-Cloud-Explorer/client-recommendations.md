# Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: AWS

I recommend AWS for the startup because it has many services that can support a mobile application. AWS provides services such as Amazon EC2 for computing, Amazon S3 for storage, and AWS Amplify for building and deploying mobile and web applications. The startup can use these services as it develops its application and can increase its resources as the number of users grows.

### Services
- Amazon EC2
- Amazon S3
- AWS Amplify


## Client B – University

### Recommended Cloud Platform: Microsoft Azure

I recommend Microsoft Azure for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure is a good match for organizations that already use Microsoft technologies. The university can also use Azure to connect cloud services with existing systems while moving some services to the cloud.

### Services
- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network


## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud

I recommend Google Cloud for the AI research company because the company needs high-performance computing for AI and machine learning. Google Cloud provides computing infrastructure with accelerators such as GPUs and TPUs that can be used for demanding workloads. It also provides services for AI, machine learning, and Kubernetes, which are useful for developing and running these applications.

### Services
- Compute Engine
- Google Kubernetes Engine (GKE)
- Cloud Storage


## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

I recommend AWS for the global e-commerce company because it has a global infrastructure with Regions and Availability Zones. This can help the company build highly available applications for customers in different locations. AWS Auto Scaling can also adjust computing resources based on demand, which is useful when the number of customers changes.

### Services
- Amazon EC2
- AWS Auto Scaling
- Amazon S3
