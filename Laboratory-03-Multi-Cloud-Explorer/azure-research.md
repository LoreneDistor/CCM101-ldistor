# Azure

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. From my research, I learned that Azure provides many cloud products and services for computing, storage, databases, networking, AI, and other IT needs. It is used by organizations of different sizes to build, run, and manage applications in the cloud.

## Global Infrastructure

Azure has a global network of datacenters organized into regions around the world. From my research, I learned that this allows organizations to choose locations for their applications based on factors such as performance, compliance, and where their customers are located. Azure also has a large global network that helps provide reliable and responsive connections.

## Cloud Management Console

The Azure Portal is a web-based management interface used to manage Azure resources and services. From the portal, users can manage applications and infrastructure such as virtual machines, storage, networks, and web apps. It also provides tools for monitoring usage, managing access, viewing costs, and getting support.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides virtual computers that can be used to run applications and workloads in the cloud. It supports different operating systems and computing requirements.

### Azure Blob Storage

Azure Blob Storage is a cloud storage service used to store large amounts of unstructured data such as files, documents, images, and backups.

### Azure SQL Database

Azure SQL Database is a managed relational database service. It allows organizations to use SQL databases in the cloud without having to manage all of the underlying infrastructure themselves.

### Azure Virtual Network

Azure Virtual Network allows users to create private networks in Azure. It can be used to connect and secure virtual machines and other Azure resources.

## Three Advantages

1. **Global reach** – Azure has a large network of datacenters and regions, giving organizations different locations to deploy their applications.

2. **Scalability** – Azure allows businesses to adjust their cloud resources based on their changing needs and workload demand.

3. **Built-in security** – Azure provides security features designed to help protect workloads and data from different types of threats.

## Typical Enterprise Use Cases

From my research, I found that organizations use Azure for application development and hosting, data storage, databases, networking, analytics, and AI. Azure can also be used for managing hybrid environments, modernizing older applications, and supporting backup and disaster recovery. Businesses can adjust their cloud resources as their needs change.
