## Questions

### 1. Which cloud provider offers the broadest range of services?

Based on my research, I found that AWS offers a very broad range of cloud services. It provides services for computing, storage, databases, networking, analytics, security, and other IT needs.

### 2. Which provider best integrates with Microsoft technologies?

I would choose Microsoft Azure for organizations that already use Microsoft technologies. Azure is a good choice because it supports Microsoft-based environments and can connect cloud services with existing systems.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Based on my research, I would choose Google Cloud for Artificial Intelligence and Kubernetes. Google Cloud has a strong focus on AI and provides Google Kubernetes Engine (GKE) for running and managing Kubernetes applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because I am interested in Artificial Intelligence and cloud computing. From my research, I learned that Google Cloud provides services for AI, data analytics, application development, and Kubernetes, which I think would be useful for improving my skills.
