# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform from Amazon. From my research, I learned that AWS provides different services that can be used for computing, storage, databases, networking, and other IT needs.

## 2. Global Infrastructure

AWS has a global infrastructure that is divided into Regions and Availability Zones. I learned that these locations help organizations run their applications in different parts of the world and improve the availability and performance of their applications.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. From the console, users can search for services, manage resources, view notifications, access CloudShell, and check account and billing information.

## 4. Four Core Services

### Amazon EC2

Amazon EC2 is a computing service that provides virtual servers in the AWS cloud. I learned that it can be used to run applications and other workloads.

### Amazon S3

Amazon S3 is a storage service used to store and retrieve data. It can be used for files, backups, and other types of data.

### Amazon RDS

Amazon RDS is a managed database service for relational databases. It makes it easier for organizations to set up and manage databases in the cloud.

### Amazon VPC

Amazon VPC is a networking service that allows users to create a virtual network for their AWS resources. It helps organize and control how resources communicate with each other.

## 5. Three Advantages

1. **Wide range of services** – AWS provides many different services that can be used for various IT and business needs.

2. **Global infrastructure** – AWS has Regions and Availability Zones in different locations, which can help organizations run applications closer to their users.

3. **Scalability** – AWS resources can be adjusted depending on the needs of an application or organization.

## 6. Typical Enterprise Use Cases

From my research, I found that organizations use AWS for hosting websites and applications, storing data, managing databases, and performing data analysis. AWS can also be used for backup and disaster recovery, software development, and other business workloads.
