# Mission Reflection

### 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Google Cloud. From my research, I learned that Google Cloud has a strong focus on Artificial Intelligence, data, and Kubernetes. I also learned that it has global infrastructure with many regions and zones for running applications.

### 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP are similar because they all provide cloud computing services. They have services for computing, storage, networking, databases, identity management, and Kubernetes. They also allow businesses to use cloud resources without having to manage all the physical infrastructure themselves.

### 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud platform is the best choice. For example, a university using Windows Server, Microsoft 365, and Active Directory can benefit from Azure because it works well with Microsoft technologies. A company focused on AI and machine learning may choose Google Cloud, while AWS can be a good option for organizations that need many different cloud services.

### 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud platform depends on the needs of the client. I had to look at each situation and decide which platform and services would be useful for the business. This helped me understand that there is no single cloud provider that is best for every organization.
