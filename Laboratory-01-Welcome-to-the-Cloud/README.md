# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduces the Linux environment, basic system information gathering, file organization, Markdown documentation, and GitHub portfolio management.

## Objectives
- Access and use a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories.
- Document technical work using Markdown.
- Create and maintain a GitHub portfolio.

## Activities Performed
- Accessed the KillerCoda Ubuntu environment.
- Created a user account and logged in.
- Gathered Linux system information.
- Created a workspace directory structure.
- Created Markdown documentation.

## Linux Commands Used
- `pwd`
- `ls`
- `hostname`
- `lscpu`
- `free -h`
- `df -h`
- `ip addr`
- `mkdir`
- `touch`
- `cat`
- `nano`

## Skills Learned
- Linux command-line navigation
- System information gathering
- File and directory management
- Markdown documentation
- GitHub repository organization
