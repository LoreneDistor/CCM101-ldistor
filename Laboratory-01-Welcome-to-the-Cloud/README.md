# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity focuses on learning the Linux environment, gathering basic system information, organizing files and directories, documenting technical work using Markdown, and creating a GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Document technical work using Markdown.
- Create and maintain a GitHub repository.

## Activities Performed
- Accessed the KillerCoda Ubuntu Linux environment.
- Created and logged in to a new Linux user account.
- Gathered system information.
- Created the required workspace directories.
- Created Markdown files.
- Prepared the Cloud Computing GitHub portfolio.

## Linux Commands Used
- `pwd`
- `ls`
- `hostname`
- `lscpu`
- `free -h`
- `df -h`
- `mkdir`
- `touch`
- `nano`
- `cat`

## Skills Learned
- Linux command-line navigation
- Linux system information gathering
- File and directory management
- Markdown documentation
- GitHub repository organization
